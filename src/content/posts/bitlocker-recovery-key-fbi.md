Es gibt Neuigkeiten zu BitLocker: Microsoft wurde gerichtlich dazu verpflichtet, einen sogenannten „BitLocker-Recovery-Key" an US-Strafverfolger – konkret das FBI – zu übergeben. Damit können Behörden mit BitLocker verschlüsselte Datenträger entschlüsseln.

## Technischer Hintergrund

BitLocker ist ein Full-Disk-Encryption-Verfahren unter Windows. Der Recovery-Key dient als Notfall-Entsperrung, falls Boot-Probleme auftreten oder das Passwort vergessen wurde. Der Key kann lokal auf einem USB-Stick oder in der Microsoft-Cloud gespeichert werden.

## Worum geht es konkret?

Microsoft wurde zur Herausgabe der Keys gezwungen, die im Microsoft-Konto gespeichert sind. Das FBI kann so vollständig verschlüsselte Datenträger entschlüsseln.

## Warum das ein Problem ist

Die Verschlüsselung selbst ist sicher, aber wenn der Recovery-Key in der Cloud liegt, existiert eine dritte Partei, die alles entschlüsseln kann. Gerichtliche Beschlüsse können schnell erlassen werden, daher verlieren Nutzer Kontrolle über ihre Daten.

## Fazit

BitLocker schützt vor Diebstahl und unbefugtem Zugriff, aber nicht gegen Hersteller oder staatlichen Zugriff, wenn der Key online liegt. Wer Kontrolle behalten möchte, sollte den Key offline speichern.
